## 3. 迁移方案

### 3.1 删除死代码 `build/`

- 删除 `build/index.js`（及 `build/` 目录）。`package.json` 的 scripts 已直接调用 `vite`，不引用 `build/index.js`，删除安全。

### 3.2 ESLint flat-config 迁移（解锁 `lint`）

- 新增 `eslint.config.js`（flat），引用 `@eslint/js`（`eslint:recommended`）、`eslint-plugin-vue` 的 flat 配置（`pluginVue.configs['flat/recommended']`），`globals`（`browser`/`node`）。
- parser 改用 ESLint 10 默认（espree），**移除 `babel-eslint`**（已废弃）。
- 将 `.eslintrc.js` 中 80+ 自定义规则**原样搬入** flat config 的 `rules`（规则名与值不变；注意 `babel-eslint` 相关项无）。
- `.eslintignore` 内容并入 flat config `ignores`（如 `dist`、`node_modules`、`tests/unit/coverage` 等）。
- 删除 `.eslintrc.js` 与 `.eslintignore`。
- `lint` script 保持 `eslint --ext .js,.vue src`（ESLint 10 默认读 `eslint.config.js`）。可选：把 `tests` 也纳入 lint（需 `env` 配 vitest globals）。

### 3.3 mock-server → Vite 插件（让 dev 的 `/dev-api` 真正可用）

- **[决策点 D1]** 自研 Vite 插件（**零新依赖**）vs 引入 `vite-plugin-mock`（新依赖）。建议**自研**：复用现有 `mock/table.js`、`mock/user.js`、`mock/utils.js`，改动最小。
- 新增 `vite.mock.plugin.js`：
  - 用 `createRequire(import.meta.url)` 加载 CJS 的 `mock/index.js`（导出 `mocks` 数组）。
  - 在 `configureServer(server)` 中，对每条 `mock` 用 `server.middlewares.use(fullPath, (req,res)=> res.json(Mock.mock(response)))` 注册；`fullPath = '/dev-api' + mock.url`（**对齐应用 baseURL `VITE_BASE_API=/dev-api`**）。
  - 支持 GET/POST（`mock.type`）。
- 删除 `mock/mock-server.js`（express 专用，已不可用）；`mock/index.js` 保留 `mocks` 聚合、移除 `mockXHR`（server mock 不需要浏览器侧 XHR mock）。
- **[决策点 D2]** mock URL 前缀：`table.js`/`user.js` 现有前缀为 `/vue-admin-template/...`，应用请求路径 = `/dev-api` + `/vue-admin-template/...`。建议**保持该前缀不变**（不改动 api 调用层），插件注册 `/dev-api/vue-admin-template/...` 即可命中。
- `vite.config.js` 引入该插件。

### 3.4 jest → vitest

- 新增依赖：`vitest`、`jsdom`（测试 DOM 环境）；移除（删除配置即可，jest 未安装无需卸）。
- 在 `vite.config.js` 增加 `test` 字段：`environment: 'jsdom'`、`globals: true`、`include: ['tests/unit/**/*.spec.{js,ts}']`、`alias: '@' -> src`（复用 resolve.alias）。或单独 `vitest.config.js`。
- 删除 `jest.config.js`。
- **重写 `tests/unit/components/Breadcrumb.spec.js`**：`@vue/test-utils` v2 已移除 `createLocalVue` 与 `wrapper.contains()`——改为直接 `mount(Component, { global: {...} })` 与 `wrapper.find(...).exists()`。其余 5 个 spec（`Hamburger`/`SvgIcon`/`validate`/`formatTime`/`param2Obj`/`parseTime`）只用 `mount/shallowMount`/`find`/`classes`/`expect`，vitest globals 下可直接跑。
- `tests/unit/.eslintrc.js`：删或改（flat config 统一配 `vitest` globals）。
- 新增 `npm run test` script：`vitest run`（CI 用）；保留 `test:watch` 可选。

### 3.5 svg-icons 插件模块化（"中间件化"）

- 将 `vite.config.js` 内联的 `createSvgIconsPlugin(...)` 抽为 `vite/plugins/svg-icons.js` 导出函数，`vite.config.js` 组合调用。
- 同步把 3.3 的 mock 插件也放 `vite/plugins/`，使配置模块化、可读性更好。低风险评估，纯重构。

### 3.6 新增 Node CI（`.github/workflows/ci.yml`）

- `on: push`(master) + `pull_request`；`runs-on: ubuntu-latest`；**Node 20**（[决策点 D4]，engines `>=18`）。
- 步骤：`actions/checkout` → `actions/setup-node@v4`（node-version 20, cache npm）→ `npm ci` → `npm run lint` → `npm run build:prod` → `npm run test`。
- 依赖 3.2（lint 通过）与 3.4（test 可用）先完成，CI 才能绿。

### 3.7 清理空 `codeql-analysis.yml`

- 0 字节空文件，无实际作用。建议**删除**（或后续按需补真实 CodeQL 工作流，不在本阶段）。

## 6. 风险与回滚

- **ESLint 规则搬运遗漏**：80+ 规则手工搬易漏；以 `npm run lint` 实测为准，逐条核对。
- **mock 路径不匹配**：务必用 `VITE_BASE_API=/dev-api` 拼接；dev 实测登录/表格接口返回 mock 数据才算闭环。
- **Breadcrumb spec 重写**：`createLocalVue`/`.contains` 替换为 `global` mount + `.find().exists()`；其余 spec 一般可直接跑，以 vitest 实测为准。
- **vitest 环境**：需 `jsdom` 提供 `document`；`@vue/test-utils` v2 配合 vitest 是标准组合。
- **CI 缓存/Node 版本**：`setup-node` 开 `cache: npm`，Node 20 与 engines `>=18` 兼容。
- 回滚：全部在 `fix/migrate-vue3-stage3` 分支；合并由你 review，不自动合并。
